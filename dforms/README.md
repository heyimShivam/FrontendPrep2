# Dynamic Form

## Problem Statement:
You have one hour. Build a dynamic form using React and a JSON configuration. The form should be able to show or hide fields based on other field values (conditional rendering), handle basic validation like required fields or patterns, and support multiple input types such as text boxes, dropdowns, and checkboxes. You can’t use react-hook-form or any third-party library.

I was given a config file — just a JSON structure — and asked to render a form out of it.
